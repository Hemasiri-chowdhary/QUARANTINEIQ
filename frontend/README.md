# QuarantineIQ V3 Frontend

Next.js frontend for QuarantineIQ's CI investigation, Hindsight memory, GitHub ingestion, Decision Challenger, and learning workflows.

Run from this folder:

```powershell
npm install
npm run dev
```

The frontend expects the API at `http://127.0.0.1:8001/api` unless `NEXT_PUBLIC_API_URL` is set.
